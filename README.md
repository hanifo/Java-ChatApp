# 💬 Java Client-Server Chat Application

## 📘 Course
Advanced Programming

## 📝 Description
This project is a Java-based client-server chat application developed using socket programming.  
It consists of two programs: ChatServer and ChatClient.

After a connection is established, both the server and client can send and receive messages simultaneously using multithreading.

## ⚙️ Technologies Used
- ☕ Java (JDK 8+)
- 🌐 Socket Programming
- 🧵 Multithreading
- 🔁 DataInputStream & DataOutputStream
- 🐙 Git & GitHub

## 🗂️ Project Structure

Java-ChatApp/ ├── 🖥️ ChatServer.java ├── 💻 ChatClient.java └── 📄 README.md

## ▶️ How to Run

### 🛠️ Compile
`bash
javac ChatServer.java
javac ChatClient.java

🚀 Run

Terminal 1

java ChatServer

Terminal 2

java ChatClient

Type exit to end the chat.
